# Commentary Intelligence — What the Evaluator Said, by Band (from 596 Scored Reports)

*Extracted 27 August 2026. The 596 reports carry evaluator commentary for every criterion (~13,000 strength/weakness statements, ~162,000 words). This file clusters that commentary into themes (paraphrased — no verbatim text) and reports, per subject and per criterion, how common each theme is within each mark band, and how it appears (as a strength or a weakness). Methodology: keyword clustering of the evaluator commentary; a report counts toward a theme if its commentary mentions it (strengths and weaknesses counted separately); themes with n < 10 in a band are flagged. Aggregate statistics only — no student data, no PII.*

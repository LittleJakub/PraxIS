# Equipment Uncertainties — School Science Instruments

Comprehensive reference for Mode A (design guidance — telling students their instrument uncertainty), Mode B (review — checking if uncertainties are correct), and Mode C (marking — verifying uncertainty treatment). Every value below is traceable to manufacturer specifications, standard analytical chemistry references, or the IB TSM conventions.

**How to use**: when the teacher names an instrument, look it up here. If it's not listed, use the general rules at the bottom and flag the specific model for the teacher to check. Never invent an uncertainty — if unsure, write "check manufacturer spec sheet" and move on.

## 4. General rules when the specific instrument is unknown

1. **Digital instruments**: uncertainty = ± half the last displayed digit (e.g., reading 24.35 → ±0.005, but in practice ±0.01 is more realistic for school instruments)
2. **Analogue scales**: uncertainty = ± half the smallest division (e.g., ruler with 1 mm divisions → ±0.5 mm)
3. **Stopwatch/timer**: uncertainty = ±0.2 s (human reaction time); justify the value
4. **Repeated measurements**: physics uses the half-range rule (larger of: half the range of repeats, or the individual reading uncertainty); biology uses SD/SEM per the n-rules; chemistry uses concordance for titrations
5. **Derived quantities**: propagate uncertainties through calculations — see `physics-conventions.md` (propagation rules) and `chemistry-conventions.md` (percentage error method)

## 5. Calibration — what to state and when

A calibration statement is cheap marks in Research design (strand 2). State:
- **Balance**: "Two-point calibration using known masses" (or "checked against a standard mass")
- **pH meter**: "Two-point calibration using pH 4.00 and pH 7.00 buffer solutions" (three-point if pH 10.00 also used)
- **Colorimeter/spectrophotometer**: "Blank calibration using distilled water" + state the wavelength used
- **Temperature probe**: "Checked against ice-water mixture (0 °C) and/or boiling water (100 °C at local pressure)"
- **Gas sensor**: "Calibrated in ambient air (20.9% O₂ / ~420 ppm CO₂)"

If no calibration was done, the student should state this — it is better to acknowledge than to ignore.
